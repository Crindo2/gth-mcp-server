Privacy Policy

GTH Intelligence MCP Server · Last updated: 2026-06-18 · Operated by CBEG Group LLC · Contact: cbeggroup@gmail.com

This policy describes how the GTH Intelligence MCP Server (https://gth-mcp-server.pages.dev/mcp) handles data. The directory itself is SAMHSA-sourced public facility data, not patient records.

What we collect

When you call a tool, we process the query parameters you supply — state, city, treatment type, and insurance — to return results. We receive your IP address from the network connection and use it solely for rate limiting. If you send a legacy API key, we track usage counts associated with it.

How we use it

To operate the service and return results, and to enforce rate limits (100 calls per IP per day).

Storage and retention

Your IP address is stored only as a per-day rate-limit counter in Cloudflare KV and automatically expires after 48 hours. Legacy-key usage counts are stored in Cloudflare KV. GTH does not log query metadata to any analytics store, and query parameters are not retained after the response is returned.

Sharing

We use Cloudflare as our hosting and infrastructure provider. We do not sell personal data and do not share query data with third parties.

What we do not collect

No patient health information, no account registration, no cookies (the service is keyless).

Changes

We may update this policy; the current version is always at this URL.
